# ERN Çiçek E-Ticaret Sitesi

[![Deploy Cloudflare Worker](https://github.com/amtbrs-03/AMTBRS/actions/workflows/deploy-worker.yml/badge.svg)](https://github.com/amtbrs-03/AMTBRS/actions/workflows/deploy-worker.yml)

Modern, statik e-ticaret sitesi. Cloudflare Workers ile serverless backend desteği.

## Özellikler

- 🌸 Ürün kataloğu ve sepet yönetimi
- 👤 Kullanıcı kayıt ve giriş sistemi
- 💳 IBAN ile ödeme entegrasyonu
- 📦 Sipariş takibi
- 🔒 GitHub tabanlı veri saklama
- ⚡ Cloudflare Workers ile hızlı API

## Teknolojiler

- Vanilla JavaScript (framework yok)
- Cloudflare Workers (serverless functions)
- GitHub API (veri depolama)
- GitHub Actions (CI/CD)

## Deployment

Cloudflare Worker otomatik olarak deploy edilir (`cloudflare-worker/**` değişikliklerinde).

## Lisans

Özel proje - Tüm hakları saklıdır.
