🔐 Passkey (WebAuthn) Yönetimi
Touch ID / Face ID veya güvenli biyometrik yöntemleri tarayıcı içinde kullanmak için Passkey oluşturun. Bu statik ortamda asgari doğrulama yapılır: kimlik id eşleşmesi. İleri seviye imza doğrulaması (attestation / assertion parse) eklenebilir.
Hazır
Nasıl çalışır?
1) "Passkey Kaydet" biyometrik ile yeni credential oluşturur.
2) ID tarayıcıda ve geçici olarak GitHub'a değil localStorage'da saklanır.
3) "Passkey ile Giriş" credential id ile doğrular.
4) Bu minimal akış tam kriptografik imza doğrulaması yapmaz (statik site kısıtı).
5) Güvenliği artırmak için ileride: authenticatorData + clientDataJSON + signature parse & verify.
