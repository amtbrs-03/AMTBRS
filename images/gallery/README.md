# Resim Galerisi

Bu dizin, admin panelinden yüklenen ürün resimlerinin toplandığı galeri klasörüdür.

Resimlerinizi buraya yükleyebilir ve admin panelinden ürünlere atayabilirsiniz.

## Kullanım

1. Admin panelindeki "📸 Galeri" butonuna tıklayın
2. GitHub'da bu klasöre yönlendirileceksiniz
3. "Add file" > "Upload files" ile resimlerinizi yükleyin
4. Yüklenen resimleri ürünlere atayabilirsiniz
